* Worked with **Next.js, React.js, .NET, MySQL and AWS**.
* Supported approximately **30K monthly bookings across 8K+ dealerships**.
* Improved synchronization and reconciliation across **4–5 independent systems**.
* Built internal dashboards supporting business and reconciliation workflows.
* Worked on production debugging, API integration and system reliability.

**Tech:** `Next.js` `React.js` `.NET` `MySQL` `AWS`

### ✈️ Delhi Airport — Airport Web Platform

Rebuilt the Delhi Airport web experience with a focus on performance, reusable components and content management.

**Highlights**

* Built responsive interfaces using **React.js, JavaScript and Tailwind CSS**.
* Improved Lighthouse performance from approximately **55 → 85**.

* Developed reusable UI components to accelerate new page development.
* Integrated booking/payment APIs and backend services.
* Implemented **Strapi CMS + Node.js/Express REST APIs + MySQL**.

**Tech:** `React.js` `JavaScript` `Tailwind CSS` `Node.js` `Express.js` `Strapi` `MySQL`
